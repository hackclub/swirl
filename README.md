# Swirl!

**Ship a website, get ice cream!**

Website for the Swirl YSWS! See it in action at [swirl.hackclub.com](https://swirl.hackclub.com).

## Local Setup

make sure you have Ruby and RubyGems installed. you can find installation instructions at [ruby-lang.org](https://www.ruby-lang.org/en/documentation/installation/).

also make sure you have bundler installed. you can install it with `gem install bundler`.

then, all you've got to do is run `bundle install` and then `jekyll serve` (or `bundle exec jekyll serve`) to start the server.
